# 30-Second Demo Video Script

## 0–5 sec
Show the application homepage.

Say:
> "This is my automated PDF Fact-Checking Agent."

## 5–10 sec
Upload the test PDF.

Say:
> "The user uploads a PDF containing factual claims, statistics, dates, or technical figures."

## 10–17 sec
Click **Fact-check PDF**.

Say:
> "The system extracts specific claims and verifies each one using live web search."

## 17–25 sec
Show the result cards.

Say:
> "Each claim is classified as Verified, Inaccurate, or False, with a corrected fact and source links."

## 25–30 sec
Show GitHub repository and deployed URL.

Say:
> "The app is deployed on Streamlit and the complete source code is available on GitHub."
